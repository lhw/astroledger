# Frontend Instructions

## Stack

- SvelteKit with TypeScript (`strict: true`)
- Skeleton UI (`@skeletonlabs/skeleton`) component library — custom Luxury Gold theme
- Vite (built into SvelteKit)
- Chart.js or Layerchart for price history graphs
- date-fns for date handling
- DOMPurify for sanitizing user-generated markdown
- ESLint + Prettier for formatting

## Theme: Luxury Gold

Dark-mode-only theme inspired by luxury spacecraft showrooms and premium touring vessels. Clean, elegant, refined.

- **Primary:** `#D4A843` (warm gold) — buttons, active states, links
- **Primary light:** `#E8C96A` (champagne) — subtle highlights, badges
- **Surface base:** `#0C0E14` (near-black, warm undertone) — page background
- **Surface raised:** `#161921` (dark gunmetal) — cards, panels
- **Accent:** `#A8B4C4` (silver/platinum) — secondary actions, ScollyBucks™ display
- **Text:** `#F0F0F0` (warm white) primary, `#8A919E` (cool gray) muted
- **Success/Error:** green-400 / red-400 (softer tones, not harsh)

The theme is defined in `src/theme.ts` and applied via Skeleton's theming system. Dark mode is the only mode. Do not implement a light theme. Use generous whitespace, smooth transitions, and thin gold accent borders. Typography should use an elegant sans-serif like Outfit or DM Sans for headings.

## Conventions

- Use Skeleton UI components (buttons, cards, modals, tables, toasts, drawers, app bars) instead of custom HTML/CSS. Theme via Skeleton tokens, don't override component styles directly.
- All API calls go through `src/lib/api.ts` — never use raw `fetch` in components. The wrapper handles base URL, credentials (`include` for cookies), error responses, and JSON parsing.
- Define TypeScript interfaces for all API response shapes in `src/lib/types.ts`. Never use `any`.
- **Auth state:** The session cookie is `httpOnly` — the frontend cannot read it. Auth state is determined by calling `GET /api/me` (via the root `+layout.server.ts` load function). The result is passed to child layouts/pages and stored in `src/lib/stores/auth.ts`.
- **Login flow:** The "Login with SCID" button navigates to `/auth/login` on the backend, which redirects to scid.my. After OIDC auth, the user is redirected back to the app with a session cookie set. No tokens are stored in localStorage.
- Use Svelte stores (`src/lib/stores/`) for shared state (auth, toasts).
- Prefer `+page.server.ts` (server load) over `+page.ts` for API calls that include cookies/auth.
- Sanitize all user-generated markdown with DOMPurify before rendering with `{@html}`. Never render raw user HTML.
- Use SvelteKit `+page.server.ts` for auth guards on protected routes (mod dashboard). Redirect to login if not authenticated.
- Keep components small and focused. Extract reusable pieces into `src/lib/components/`.

## Theming

- Use Skeleton's theming system. Aim for a dark, space-themed look that fits the Star Citizen aesthetic.
- Keep the tone satirical in copy — placeholder text should be funny, not generic lorem ipsum.
