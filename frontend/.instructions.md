# Frontend Instructions

## Stack

- SvelteKit 2 + Svelte 5 with TypeScript (`strict: true`)
- **Tailwind CSS v4** via `@tailwindcss/vite` Vite plugin — no `tailwind.config.js`, no PostCSS config
- **Skeleton UI v4** (`@skeletonlabs/skeleton`) — used for CSS reset and token base only; imported in `app.css`. Do NOT use Skeleton Svelte component wrappers. Prefer plain HTML + Tailwind or `bits-ui` headless components.
- **`bits-ui`** for headless accessible components (tooltips, calendars, etc.)
- **`lucide-svelte`** for icons (outline style only)
- `marked` + `isomorphic-dompurify` for markdown rendering and sanitization
- Vite 7 (via SvelteKit)

## Theme

The theme lives entirely in **`src/app.css`** as CSS custom properties. There is no `src/theme.ts`.

- **Light mode (default):** white body (`--app-bg`), dark charcoal nav (`--nav-bg: oklch(12%...)`), warm gold accents
- **Dark mode:** toggled via `data-theme='dark'` on `<html>`, controlled by `src/lib/stores/theme.ts`
- **Primary gold:** `oklch(69% 0.140 75)` ≈ `#D4A843`
- Inspired by the RSI ship page aesthetic (robertsspaceindustries.com) — clean editorial, warm gold on crisp white/deep charcoal

Do NOT implement a dark-only theme. Both light and dark modes are fully supported.

## Svelte 5 Conventions

- Use **runes syntax**: `$state`, `$derived`, `$derived.by`, `$effect`, `$props()`, `{@render children()}`
- No `$:` reactive declarations. No `export let` in new code — use `$props()`.
- Layout uses `{@render children()}` not `<slot />`

## Conventions

- **No raw `fetch` in components.** All API calls go through `src/lib/api.ts`.
- Define TypeScript interfaces for all API shapes in `src/lib/types.ts`. Never use `any`.
- **Auth state:** session cookie is `httpOnly` — frontend cannot read it. Auth determined by `GET /api/me` on mount via `initAuth()` in the root layout. State stored in `src/lib/stores/auth.ts`.
- **Login flow:** navigate to `/auth/login` (backend handles OIDC redirect). No tokens in localStorage.
- Prefer `+page.server.ts` (server load) over `+page.ts` for API calls needing cookies.
- Sanitize all user markdown with DOMPurify (`src/lib/markdown.ts`) before `{@html}`. Never render raw user HTML.
- Use `+page.server.ts` auth guards on protected routes (mod, admin). Redirect to login if unauthenticated.
- Analytics: fire `POST /api/analytics/hit` in `afterNavigate` (already in root layout — don't add it again to pages).
- Keep the tone satirical — placeholder text should be funny, not generic lorem ipsum.
